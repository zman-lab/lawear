### 절대 보존 (압축 금지)
- 조문 [case] 100% verbatim
- 판례·선례·예규 명시 라벨 (룰 6) — "**판례는** ~", "**선례에 따르면** ~", "**예규에 의하면** ~"
- 정형구 핵심 (룰 5) — 조문 어미·정식 용어·인과 표현
- 결론 키워드 — 각하/수리/직권말소/부활/유효/무효 등

### 적극 압축 (30~40% 줄이기)
- 부연 설명 ("이 경우에", "이는", "이러한", "다만 그") — 지시어 적극 삭제
- 중복 표현 — 케이스명 본문 반복 제거
- 사안 적용 본문 통합 — 별도 섹션 X, 결론에 통합
- 단락 압축 — 1단락 → 1줄
- 어순 단순화 — 주절 + 단서 합치기
- 평어체 종결 통일 ("~한다" / "~이다")

**판정 알고리즘**:
```python
case_count = len(re.findall(r'\[case\]', md_content))
example_count = len(re.findall(r'예컨대|예를 들어', md_content))
red_count = len(re.findall(r'\[red\]', md_content))

if case_count >= 5 and red_count <= 3:
    type = "A"
elif case_count == 0 and example_count >= 2:
    type = "B"  # 압축 X 권고
else:
    type = "C"
```

## 눈뽕 방지 (2026-05-25 lawear-18eb)

Lv.4 압축본 생성 시 하이라이트 과다("눈뽕") 금지:
- **`[u]` 통밑줄 사용 금지** — 눈뽕 주범(강사 진단). 강조는 `[em1]`~`[em4]` 두문자 골격 + `[con]`/`[case]`/`[key]`/`[fact]`/`[bridge]` 폰트로.
- **`[red]` 판단·결론어 한정** (각하·수리·직권말소·부활·무효·원시취득 등 짧은 어절). 긴 설명구는 강조 X 또는 `[em2]`.
- **`[blue]` 법령어 한정.** 1문장 최대 2종 강조.
- **`[case]` 종류 차등**: 조문·규칙 인용부 본문강조 약화(번호만 외우면 전사 가능), 판례·선례·예규는 보존(암기 대상).
- 원본(`docs/tts-new/`)에 `[u]` 잔존 시 압축본에서는 제거(텍스트 byte 보존). 정리 스킬: [[dev-le-17895-nunppong-sweep]].
- 골격 `[em1]`~`[em4]`는 눈뽕 아님(목차 구조 표지·암기 인덱스) — 유지.
