# le-emphasis-apply — Lv.4 강조 태그 메인 수동 보강 스킬

> A 스크립트(`scripts/apply_emphasis_lv4.py`)의 자동 매칭 후 누락된 강조 태그를 메인 Claude가 수동으로 의미 매칭하여 보강한다.
>
> A 자동 매칭 정확도 ~41% → B 수동 보강 후 95%+ 달성.

## 언제 사용하나

- A 스크립트 실행 후 .md의 Lv.4 강조 태그 적용률이 70% 미만일 때
- PDF 강조 키워드가 사용자 정답지 표현으로 변형되어 substring 매칭 실패한 경우
- 부장판사 QA에서 강조 키워드 누락 보고된 경우

## 입력

- 변환된 .md 파일 (예: `docs/tts-new/입문_민법/2026_minbeop_immun_미케01_NN.md`)
- 해당 PDF JSON (예: `pipeline/raw_texts/minbeop/immun_mike01.json`)
- 사용자 정답지 (`/Users/nhn/Documents/암기노트/민법/26_민법_미케.txt`)
- 예: `le-emphasis-apply 미케01_01`

## 사전 로드 (필수)

1. **A 스크립트로 1차 자동 적용 먼저 실행**: `python3 scripts/apply_emphasis_lv4.py --file 미케NN`
2. 위 .md 파일을 Read (전체)
3. 해당 JSON Case 데이터 Read (`answer.sections[].content`의 [red]/[blue]/[bold] 키워드 추출)
4. 사용자 정답지 매핑된 Case 본문 Read (le-lv4.md 매핑 표 참조)

## 워크플로우

```
1. JSON에서 강조 키워드 전체 추출 (red/blue/bold)
2. 각 키워드별로 Lv.4 본문에 매칭 시도:
   a. 정확 substring 매칭 (A 스크립트가 이미 처리한 부분 — 스킵)
   b. **의미 매칭** (메인이 직접):
      - PDF "제34조의 규정" ↔ Lv.4 "제 34조 법인의 권리능력" — 같은 의미
      - PDF "직접 간접으로 필요한 행위" ↔ Lv.4 "직접 간접 필요 행위" — 표현 변형
      - PDF "사원총회의" ↔ Lv.4 "사원총회 결의를" — 어절 변형
   c. 사용자 정답지 매핑 Case의 강조 패턴 참고 (사용자가 어떤 부분 강조했는지)
3. 의미 매칭된 위치에 태그 감싸기:
   a. Edit으로 정확한 substring + 태그 적용
   b. 이미 다른 태그 안에 있으면 중첩 회피 (R-28 우선순위: blank > red > blue > bold)
4. R-09 자가 검증:
   - 추가한 태그가 모두 PDF 또는 사용자 Case에 있는 표현인지
   - 메인이 임의로 새 표현 만들지 X
5. 적용 통계 보고 (A 자동 N개 + B 수동 M개 = 총 K/T = X% 적용)
6. 게시판 lawear-work에 보고 (선택)
```

## 의미 매칭 룰

### M-1. 동의어·표현 변형 인정
- PDF "제34조의 규정" ↔ Lv.4 "제 34조 법인의 권리능력" — **OK** (같은 조문)
- PDF "유추적용" ↔ Lv.4 "유추적용한다" — **OK** (조사 변형)
- PDF "사원총회의 결의" ↔ Lv.4 "사원총회 결의" — **OK** (조사 생략)

### M-2. 부분 매칭 (4자 이상 핵심 단어)
- PDF "결의를 거치지 않은 총유물의 관리 및 처분행위는 무효" 긴 키워드
- → Lv.4의 핵심 단어 "결의를 거치지 않은" 또는 "총유물의 관리" 또는 "처분행위는 무효" 부분 매칭

### M-3. 중첩 회피 (R-28 우선순위)
- 이미 [red]/[blue]/[bold] 태그 안의 부분에 [blank] 우선 적용
- [red] 안에 [blue] 또는 그 반대는 X
- 가장 높은 우선순위 1개만 적용 (blank > red > blue > bold)

### M-4. R-09 보존 (절대 금지)
- PDF에도 사용자 Case에도 없는 표현에는 태그 추가 금지
- 의미 매칭이라도 원본에 없으면 자의적 추가로 간주

## 출력 형식

각 .md의 Lv.4 섹션에만 강조 태그 인라인 삽입. 다른 섹션은 건드리지 않음.

```markdown
## Lv.4 암기노트 (사용자 스타일)
결론, ~.
1. 비법인사단이란, [blue]규약과 단체로 조직을 갖출것[/blue], ...
2. A조합은 재건축조합으로 비법인사단에 해당하며, 그 재산의 [red]소유 형태는 총유[/red]이다.
...
```

## 권장 호출 패턴

```
# 1. A 자동 적용 먼저
python3 scripts/apply_emphasis_lv4.py --file 미케01

# 2. 적용률 확인 (스크립트 출력)
# 41% 미만이면 B 스킬 호출
/le-emphasis-apply 미케01_01

# 3. 메인이 .md + JSON + 사용자 Case Read → 의미 매칭 → Edit으로 태그 적용
# 4. 최종 적용률 보고
```

## 자가 검증 체크리스트

- [ ] R-09: 모든 추가 태그가 PDF 또는 사용자 Case에 있는 표현인가?
- [ ] R-28 우선순위: blank > red > blue > bold 따랐는가?
- [ ] 중첩 회피: 한 부분에 하나의 태그만 적용되었는가?
- [ ] 빈 줄 보존: Lv.4 본문 구조 (번호 + 내용) 유지되었는가?
- [ ] 적용률: A 자동 + B 수동 = 70% 이상 달성했는가?
