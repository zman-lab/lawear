# le-pdf-load — PDF 필기/하이라이트 추출 가이드

> PDF 스캔 이미지에서 사용자 필기·하이라이트를 추출할 때 호출.
> 수동 호출 전용: `/le-pdf-load`

## 사용자 표기 규칙

### 강조 (본문)
- 밑줄(진한색): 텍스트 강조 (형광펜 대신)
- 동그라미: 키워드 강조 (닫힌 형태)
- 별표(★)/느낌표(!): 여백에 중요 표시

### 메모 연결 (본문 ↔ 여백)
- 동그라미 시작점에 A, B, C 태그
- 화살표로 여백 메모까지 연결
- 여백 메모에도 동일 A, B, C 태그
- AI는 화살표 형태 무시, 알파벳으로 매칭

### 색깔 구분
- 용도별 1색 고정 (빨강=핵심, 파랑=의문, 초록=보충 등)
- 글씨 색과 반대 계열로 형광펜 (빨간글씨+주황형광 X)

## AI 추출 규칙

### 적극 추출
- 진한색 밑줄/동그라미 → 색깔+텍스트
- 여백 또박또박 메모 → 알파벳 태그로 본문 매칭
- 별표/느낌표 등 단순 기호

### 판독 불확실한 항목 처리
- 결과물에 넣지 않는다
- 콘솔에 별도로 사용자에게 알림 (어떤 항목이 불확실한지 정리)
- 형식 자유 (표, 목록 등)

## 출력 형식

### 구조
1. 목차 (결론 아래 목차부터 시작)
2. 각 섹션별 필기/하이라이트 내용

### TTS 호환 형식 (표 금지)
- TTS로 들을 수 있는 텍스트 형태로 출력
- 표(table) 사용 금지
- 예시:

```
Ⅰ. 결론
Ⅱ. 근거
  1. 청구의 병합
  2. 대여금청구에 관하여
  3. 지연손해금청구에 관하여

---

1. 청구의 병합
- (노랑 밑줄) "각 소송물을 달리하는"
- (빨강 동그라미) "객관적 병합"
- A. 여백 메모, "관련청구 = 견련관계 있는 청구"

2. 대여금청구에 관하여
- (노랑 밑줄) "소비대차계약의 체결사실"
- (노랑 밑줄) "금전을 지급한 사실"
- (노랑 밑줄) "변제기 도래사실"
- (빨강 동그라미) "제598조, 제603조"
```
