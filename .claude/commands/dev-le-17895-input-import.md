**누락이 불가피한 경우 메인 보고서 제출 의무**:
- 서브에이전트 결과 JSON에 `omitted_citations` 필드 **강제** (필드 자체 누락 금지)
- 형식:
  ```json
  "omitted_citations": [
    {"file": ".md 경로", "pdf_ref": "강사 PDF 위치 (예: 1페이지 Ⅰ.1.②)", "citation": "조문/선례/예규", "reason": "누락 사유"}

  ```
- 누락 0건이면 빈 배열 `[]` 명시
- 보고하지 않고 자율 누락 = 룰 위반

**메인 fallback**:
- 서브 보고가 부정확하거나 누락 보고 자체가 빠지면 메인이 강사 PDF 직접 read + .md 결과 grep 대조

##### (C) 목차 깊이 = "표준 골격 고정 + 사례별 nesting" (2026-05-24 사용자 확정 설계)

**3단 깊이 표준 (표준 2단 + 사례 1단)**:

| 단 | 정체 | 본문 표현 | 출처 |

   - 사례 3단 본문 라벨 예: `가. [em2]등기능력 있는 부동산일 것[/em2]` 다음 줄부터 번호목록 설명. (`####`/`#####` 헤딩 X — `가.`/`나.`로 시작하는 평문 라벨에 [em] 강조)
   - 아주 깊은 사례(드묾)만 4단 본문 라벨 허용. 통상은 3단에서 끝.
2. **em ≠ 목차 깊이 (역할 분리)**: `[em1]~[em4]`/`[red]`/`[blue]`/`[u]`/`[case]`는 **본문 강조 역할**이다. 목차 깊이를 em 레벨(4단)까지 끌고 가지 말 것. 목차는 제목 3단(h3/h4/본문라벨), em은 본문 강조 — 역할이 다르다.
   - 표준 중목차 #### 제목은 평문 기본 + 핵심어/짧은 제목 전체/[case]만 절제 강조 가능 (긴 제목 도배·[u] 금지): `#### 의의`, `#### [red]의의[/red]`, `#### 신청인 [case]제23조 등기신청인[/case]`, `#### [em1]서설[/em1]`.
   - 사례별 3단 본문 라벨([em] 마킹)은 본문이므로 [em2] 등 자유: `가. [em2]등기능력 있는 부동산일 것[/em2]`.
   - 본문 번호목록 안 인라인 [u][red][blue][em1~4][case]는 자유.
3. **R-09 라벨/계층만 정리 — 본문 보존**: 강사 답안 내용을 정본 템플릿 칸(Ⅰ/Ⅱ/1/2)에 **매칭**해 표준 슬롯에 배치한다. **칸 이름(대/중목차)·계층(어느 표준 슬롯 아래인지)·사례 라벨(가/나/다)만 정본화**하고, **본문 텍스트·조문([case])·강조([em])·강사 고유 표현은 절대 보존**(요약/재구성/삭제 금지). 정본 템플릿에 없는 강사 고유 소단원은 가장 가까운 표준 슬롯 아래 본문([em]-라벨)으로 수용(임의 h4 신설 지양).
4. **라벨 정본화 (축 뒤집힘 교정 — 사용자 명시)**: `가1/나1/가2/나2`처럼 **축이 뒤집힌 뒤죽박죽 라벨(숫자=카테고리, 글자=항목, 또는 그 반대로 섞임)을 정본 카테고리 구조로 정리**한다.
   - 만능목차 **첨부정보 정본 구조** = `등기원인 관련`(등기원인증명 / 등기원인 허가·동의·승낙) · `의무자 관련`(등기필정보 / 인감증명 / 주소증명) · `권리자 관련`(세금영수증 / 주소증명 / 번호증명) · `부동산 관련`(대장 등) · `신청인자격 관련`. (만능목차 8p §3.첨부정보 그대로)
   - 정리 방향: **카테고리(등기원인/의무자/권리자 관련)는 사례 3단 라벨(가/나/다)로, 그 아래 구체 서면(등기원인증명·세금영수증 등)은 더 깊은 항목으로** 일관 정렬. 카테고리와 항목이 라벨 축에서 섞이지 않게 한다.
   - **R-09**: 라벨/계층만 정리, 본문 텍스트·조문([case])·강조([em])는 그대로 보존. "해당 없다"도 보존.
5. **부분 출제**: 템플릿 전체(Ⅰ~Ⅳ)를 안 묻으면 **닿는 대/중목차만** 발췌(없는 칸 억지 생성 금지). 예: "유효기간만 약술" → ② 템플릿 `### 제공절차` > `#### 유효기간`만.
6. **#### 생략이 정상 (단답형)**: 짧은 단답형(결론·이유만, 통상 7~15점, 표준 중목차 계층 미도달)은 `### 결론`/`### 이유` + 번호목록으로 끝. #### 억지 금지.
7. **`## 답안` 내 별도 "목차" 소제목 중복 금지**: 답안 구조는 인라인 `###`/`####`로 충분. 상단 `## 목차`(§2-6-3)와 별개로 답안 안에 "목차" 소단원 또 만들지 말 것.

**정합 예시** (`2026_사용자_부동산등기법/입문/14_예상문제.md` — ③ 등기절차 유형, 직권보존, 20점). 표준 골격(`### 주제` > `#### [em1]서설/개시/촉탁절차/실행절차[/em1]`) 고정 + 사례 3단을 본문 [em]-라벨로 nesting:
```
### 종중 미등기건물 가압류등기 촉탁의 사전절차
#### [em1]서설[/em1]
1. [em2]의의[/em2] ([case]제66조 미등기부동산의 처분제한의 등기와 직권보존[/case])
   1. 본문...
2. [em2]요건[/em2]
   가. [em2]등기능력 있는 부동산일 것[/em2]      ← 사례 3단 = 본문 [em]-라벨 (h5 금지)
   1. 본문...
   나. [em2]법원의 촉탁일 것[/em2]
   1. 본문...
#### [em1]촉탁절차[/em1]
3. [em2]첨부정보[/em2] ([case]규칙 제46조 첨부정보[/case])
   가. [em2]등기원인 관련 정보[/em2]            ← 라벨 정본화: 카테고리=가/나/다
   - 등기원인증명 ([case]규칙 제46조 첨부정보 제1항 제1호[/case])  ← 구체 서면=하위 항목
   나. [em2]의무자 관련 정보[/em2]
   다. [em2]권리자 관련 정보[/em2]
   - 세금영수증 / 주소증명 / 번호증명
```
(주의: 현재 14_예상문제는 첨부정보 라벨이 `가1/나1/가2/나2`로 축이 뒤섞여 있음 → 4번 라벨 정본화 적용 대상. 본문·[case]는 보존하고 라벨/계층만 위 카테고리 구조로 정리.)

#### 2-6-3. 부등법 상단 `## 목차` 섹션 (사용자 요구 — **부등법 전용 조건부 룰**, 2026-05-24 추가)

**적용 대상**: 부동산등기법(budeunglaw)만. 다른 4과목은 미적용.

**근거**: 사용자 — "부등법은 #### 된 것이라도 상단 문제/목차/답안 구조 자체가 없으니 해야 한다." 모든 부등법 .md를 `## 메타 → ## 문제 → ## 목차 → ## 답안` 순서로 구성. `## 목차`는 **선택한 정본 템플릿(§2-6-2)의 대목차+중목차 요약(암기 인덱스)** — 사용자가 상단 목차를 먼저 보고 만능목차 골격을 회상해 누락을 방지.

**위치**: `## 문제` 다음, `## 답안` 앞 (고정).

**형식** (3단 nesting — §2-6-2 (C) "표준 골격 + 사례 nesting"과 동일 깊이. 답안 헤딩/라벨과 1:1):
1. **1단 = 대목차(표준)**: 선택 템플릿 대목차(Ⅰ/Ⅱ/Ⅲ/Ⅳ → 답안 `### {대목차}`)를 `1. 2. 3.` 번호로 나열.
2. **2단 = 중목차(표준)**: 그 아래 중목차(1/2/3 → 답안 `#### {중목차}`)를 3칸 들여쓴 `- `로 나열.
3. **3단 = 사례별**: 그 아래 이 문제 고유 사례 라벨(답안 본문 `가./나./다.` [em]-라벨)을 6칸 들여쓴 `· `로 나열. (사례 슬롯이 깊으면 핵심 라벨만 — 답안 본문에 실제 등장한 것과 1:1.)
4. **평문화**: 모든 단의 텍스트는 답안 헤딩/라벨에서 **강조태그·[case] 벗긴 평문** (답안 `### 신청절차 [red]키워드[/red]` → `1. 신청절차 키워드`, 답안 `#### [em1]서설[/em1]` → `- 서설`, 답안 본문 `가. [em2]등기능력 있는 부동산일 것[/em2]` → `· 등기능력 있는 부동산일 것`).
5. **부분 출제**: 답안에 실제 등장한 단만 나열(없는 칸 억지 X — 답안과 1:1).
6. **단답형(#### 없음)**: 대목차(`### 결론`/`### 이유` 등)만 번호 나열, `-`/`·` 하위 없음.

**예시** (③ 등기절차 유형, 직권보존 — §2-6-2 (C) 정합 예시 14_예상문제 기준. 표준 2단 + 사례 1단 = 3단):
```markdown
## 목차

1. 종중 미등기건물 가압류등기 촉탁의 사전절차
   - 서설
      · 의의
      · 요건
      · 범위
   - 개시
   - 촉탁절차
      · 촉탁인
      · 촉탁정보
      · 첨부정보
   - 실행절차

## 답안

### 종중 미등기건물 가압류등기 촉탁의 사전절차
#### [em1]서설[/em1]
1. [em2]의의[/em2] ...
```
(사례 3단을 다 펼치면 길어질 땐 답안 본문에 [em2]-라벨로 실제 등장한 핵심 항목만 — 답안과 1:1 유지. 단답형은 1단만.)

단답형 예시:
```markdown
## 목차

1. 결론
2. 이유

## 답안

### 결론
...
```
