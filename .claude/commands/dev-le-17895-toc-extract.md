## 배경
- 24/25(민법/민소) = `## 원본`(문제+답안 통째 보존) + `## Lv.1`(### 문제/### 목차/### 답안) + `## Lv.4`(암기노트).
- Lv.1 강사 목차가 원본 답안의 2~3단 계층을 **평탄화**(예 "사실의 주장책임 — 주요사실 / 사실자료" ← 하위 2개를 `—`로 합침).
- 부등법 `## 목차`(H2)는 user-toc 박스(파란 띠)로 렌더되나, 미케 `### 목차`(Lv 안 H3)는 plain이었음 → `wrapLvToc`로 해결.

## 목차 형식 (부등법 일치 — 필수)
- **1단**: `1. 2. 3.` (숫자 + 점)
- **2단**: `   - ` (3칸 들여쓰기 + `-`)
- **3단**(필요 시): `      · ` (6칸 + `·` middle dot)
- ⚠️ **`-` 2칸 금지** — 마크다운 중첩 렌더가 깨짐(1단도 `-`면 부등법과 다르게 렌더). 반드시 1단 숫자 + 2단 3칸 `-`.

## 작업 단계
1. **## 원본 답안 쟁점 헤딩 파싱**: `(1)(2)(3)` > `1)2)` (또는 설문별 `Ⅰ/Ⅱ/Ⅲ` > 하위) 등 쟁점 계층.
   - **제외**: 포괄 대분류(`1. ~위반 여부`)·사안적용(`2. 사안의 경우`) — 순수 쟁점만.
   - 설문 여러 개면 설문별로.
2. **계층 목차 생성**(위 형식). 원문 답안 헤딩 **verbatim**(자의 재작성·요약 금지).
3. **Lv.1 `### 목차` 교체**: 기존 평탄 → 계층.
4. **Lv.4 `### 목차` 신설**: `## Lv.4 암기노트` 바로 다음 + `[con]` 앞. Lv.1 목차를 **복붙**(동일).
5. **## 원본 0변경**(R-09 — 원본은 전사 보존, 절대 건드리지 말 것).

## 렌더 (merge.html `wrapLvToc` — 이미 적용됨)
```js
function wrapLvToc(html) {
  return html.replace(/<h3[^>]*>\s*목차\s*<\/h3>\s*(<ol[\s\S]*?<\/ol>)/, '<div class="user-toc"><span class="toc-label">목차</span>$1</div>');
}
```
- `showSection('전체')` Lv1/Lv4 컬럼 + 개별 Lv 탭 렌더에 `wrapLvToc(renderMd(...))` 적용.
- 정규식 **`<ol[\s\S]*?</ol>` (ol 전용)** — `(?:ol|ul)`로 하면 중첩 `</ul>`에서 끊겨 마지막 li가 박스 밖으로 나가는 버그. ol만 닫음(중첩 ul 포함).
- 전 과목 자동(Lv 목차 있는 모든 .md).

## 복붙 vs 캐시 (확정: 복붙)
- 목차는 한번 뽑으면 불변 → 동적 캐시 불필요(YAGNI). .md 자체 완결(다운로드·외부서도 목차 보임, 뷰어 무관). 캐시/동적 로드는 뷰어 렌더 로직 추가라 버그 위험.
- 중복은 "생성 시 1회 추출 → Lv1/Lv4 양쪽 삽입"으로 해소(런타임 캐시 아님).
