### 1. 정량 분석 (참조 샘플 N개 + 대상 1개)

### 2. 태그 사용 분석 (참조 샘플별)


태그 의미:

## TTS 친화 특수문자 변환 가이드

| 도비 자의 (금지) | 자연어 변환 |
|------------------|-------------|
| `A → B` | `A는 B가 된다` / `A이면 B이다` |
| `A = B` | `A는 B이다` / `A, 즉 B` |
| `A / B` | `A와 B` / `A 또는 B` |
| 표 `\|---\|` | 자연어 목록 (`*` `-`) |
| `A·B·C` | `A, B, C` (사용자 묶음 두문자는 예외 — verbatim) |
