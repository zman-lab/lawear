# le-lv4 — 암기노트 TTS 변환 스킬

> Lv.4 암기노트 TTS 변환. **사용자가 직접 작성한 정답지 스타일을 학습해 적용.**
> 입력: 원본 PDF 또는 Lv.1/2/3 TTS 텍스트
> 출력: 결론 한 줄 + 평면 번호 매김(1, 2, 3, ...) 답안
>
> **핵심 원칙**: 사용자 작성본 = 정답. PDF는 원본, 사용자가 어떻게 변형했는지가 정답.

## 언제 사용하나

- 시험 직전 핵심만 입으로 외우는 "암기노트" 형식이 필요할 때
- A/B/C/F 구조도 덜어내고 결론 + 번호 명제만 남기고 싶을 때
- 사용자 직접 작성 스타일(민법 미케 Case 1~30)을 다른 문제에도 확장 적용할 때

## 입력

- 원본 PDF 또는 Lv.1/2/3 TTS 텍스트 파일
- 예: `le-lv4 민법_미케01_07.md`

**1. 가이드 파일 전체 Read 필수:**

**2. 사용자 작성본 직접 참조 (필수, 매번):**

- **변환 전 같은 주제 Case 명시적 매칭 + Read 필수**:
  - 비법인사단 / 대표권 제한 → Case 21

## 출력 형식

```markdown
## Lv.4 암기노트 (사용자 스타일)
결론, ~.
1. ~
2. ~
3. ~
...
N. (필요 시 사안 포섭)
```

- **문제/목차/F 섹션 없음** (Lv.4 고유 — Lv.1/2와 다름)
- 결론 한 줄 → 평면 번호 답안 → (필요 시 마지막 번호에 사안 포섭)
- diff (원본 vs Lv.4)
- 체크리스트 10개 (le-dev 기준 동일)
- R-01~R-26 적용 표

## 규칙

### 절대 룰 (가이드 §0)

1. **사용자 작성본 = 정답**. PDF가 정답 아님.
2. **R-09 (자의적 해석 금지)** 최우선.
3. **사용자 축약/오타 보존**: "항병권", "중계료", "제 397조" 띄어쓰기 등 사용자 패턴은 교정 X.
4. **사용자 결론 vs PDF 결론 충돌 시 → PDF 우선** (R-09 의심 사례 회피).

### Lv.4 핵심 패턴 (P-01~P-10 요약)

| 패턴 | 내용 |
|------|------|
| P-01. 결론 한 줄 | 첫 줄 `결론, ~` 형식. 마침표/콜론 금지. 쉼표 다수. 복잡 쟁점은 복문. |
| P-02. 평면 번호 | `1. ~` `2. ~` 평면. PDF의 1-(1)-① 계층은 모두 1차원 flatten. |
| P-03. 조문 띄어쓰기 | **Lv.4 한정** `제 397조` (공백 유지) — Lv.1/2/3과 다름. |
| P-04. 판례 결론만 | "판례는 ~ 했다". 판례번호 제거. 전합/변경판례는 본문 일부 이식 가능. |
| P-05. 학설 제거 | 학설 대립 완전 제거. 판례 입장만. |
| P-06. 한자 → 한글/역할 | 甲乙丙丁 → 갑을병정 또는 "제1매수인" 등 역할. A/B/C/D/E는 유지. |
| P-07. 숫자/날짜 | 금액은 쟁점 아니면 삭제. 시효 날짜는 유지. 조문/목록 번호 아라비아 그대로. |
| P-08. 요건 나열 | "A, B, C이다" 쉼표 연결. 말미 "을 요한다" / "이다". |
| P-09. 사안 포섭 통합 | 별도 F 섹션 X. 마지막 번호 또는 결론에 통합. 생략도 가능. |
| P-10. 섹션 제거 | 문제/목차/F 전부 없음. Case N → 결론 → 1. 2. ... 만. |

### 길이 체감 + 풍부함 기준 ⭐

- Case 전체 **15~40줄** (단순 케이스 Case 9는 1줄, 복잡 Case 18/23은 12~13개 번호)
- 평균 번호 수 **7~9개** (최소 0개, 최대 13개)
- 각 번호 **1~5줄** (판례 본문이나 법리 단계 부연 시 5~10줄)

#### P-11. 풍부함 체크리스트 ⭐ (R-09 자의적 해석 금지 범위 내에서)

| 항목 | 좋은 예 (사용자 정답지 Case 21 등) | 나쁜 예 (지양) |
|------|----------------------------------|---------------|
| **개념 정의** | "비법인사단이란, 규약 갖출것, 다수결 의결, 존속성, 주요사항 확정을 요하며, 조합 명칭 불구 위 요건 시 해당한다" (요건 풀어서) | "재건축조합은 비법인사단이다" (결론적 적용만) |
| **부가 개념** | "비법인사단이고 소유 형태는 총유이다" (지위/소유형태 명시) | 부가 개념 누락 |
| **조문 인용** | "제 34조 권리능력은 비법인사단에 유추적용되어 ~ 권리의무 주체이며, 목적범위란 ~ 직접 간접 필요 행위를 포함한다" (한 번호에 2~3 명제) | "제 34조 유추적용" 단답 |
| **판례 부연** | "판례는 ~ 법률적 사실적 처분행위와 이용 개량을 말한다, ~ 채무부담일 뿐이라 했다" (판례 논리 단계) | "판례는 X" 단답 |
| **사안 포섭** | "사안에서 ~이고, ~이며, 따라서 ~ 한다" (사실→법리→결론) | "사안에서 X" 1줄 |
| **단계 분리** | 큰 법리 단계마다 별도 번호 | 한 번호에 5~6 단계 통합 |

**적용 원칙:**
- 사용자 정답지에서 7~9개가 일반적, 12~13개도 종종 있음 (Case 18, 23). 짧게 7개로 끝낼 수도 있지만 한 번호의 깊이는 확보.
- R-09 (자의적 해석 금지) 우선: 원본 PDF/Lv.1에 없는 법리/판례 추가 금지. 다만 **PDF에 있는 내용은 누락 없이 풀어서** 가져온다.
- 한 번호에 명제가 2개 이상이면 쉼표(,)로 연결하거나 같은 번호 안에 줄바꿈으로 단계 표시 (사용자 Case 5/6/7 패턴).
