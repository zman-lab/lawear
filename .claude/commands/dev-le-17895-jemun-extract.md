# dev-le-17895-jemun-extract — 제N문 PDF 답안 추출 → ## 원본 채움

> 24/25 민법·민소 .md의 `## 원본`이 비어있거나(SKIP) 문제만 있을 때(답안 누락), PDF에서 제N문 모범답안을 추출해 채운다. R-09 verbatim. 자동추출 분할 실패분(보통 제1문) 복구.

## 트리거
- `/dev-le-17895-jemun-extract {.md 경로}`

## 배경 — 박문각 모의고사 PDF 구조
PDF는 보통 `[문제지: 제1문 문제][제2문 문제] + [해설지: 제1문(문제재기술+답안)][제2문(...)] + [답안지 양식]` 배치.
- `_01` = 제1문, `_02` = 제2문.
- **해설지 제N문 블록**(문제 재기술 + 모범답안)이 한 덩어리 → 이게 `## 원본`에 맞음(동급 완성본 10_01 구조와 일치).
- 자동추출(extract_pdf_text.py)이 제2문은 성공하나 **제1문 분할 실패** 빈번 → 본 스킬로 복구.

## 워크플로우
1. **메타에서 PDF 경로** 읽기. `pdfinfo`로 페이지 확인.
2. `pdftotext "{PDF}" /tmp/x.txt` (plain — layout 옵션 X. 답안부 붙어쓰기는 PDF 특성, R-09상 그대로 OK).
3. **경계 탐색**: `grep -nE "제\s?[12]\s?문"` → 제1문/제2문 문제·해설 위치. 해설지 제1문 블록 = `제1문`(해설) ~ `제2문`(해설) 직전.
4. **답안 시작점**: 해설 블록 내 `grep -nE "관하여|결\s*론|^\s*Ⅰ"` → `Ⅰ. 설문 1.에 관하여` 등.
5. **슬라이스 + ## 원본 삽입**:
   - 원본 비어있음(SKIP) → 해설지 제N문 블록 통째(문제재기술+답안) 삽입.
   - 문제만 있음(답안 누락) → 기존 문제 보존 + 답안부(`Ⅰ.` 이후)만 append.
   - 선두 `제1문` 헤더줄 + 후미 페이지마커(`- N -`)·빈줄 strip. 내부 페이지마커·각주는 보존(템플릿 관례).

## ⚠️ 치명 버그 회피 (2026-05-25 lawear-18eb 실경험)
- ## 원본 삽입 시 정규식 `## 원본` 으로 매칭하면 **메타의 "상태: ## 원본 자동 추출 …" 문구에 먼저 매칭**되어 진짜 `## 원본 (NN점)` 헤더가 body로 먹혀 삭제됨.
- **반드시 `^## 원본 \(\d+점\)` (줄 시작 + 점수 괄호) 앵커**로 매칭하거나, 메타 영역(`## 메타`~다음 `##`)을 제외하고 탐색.
- 삽입 후 `grep -n "^## " {md}`로 `## 원본 (NN점)`·`## Lv.1`·`## Lv.4` 3섹션 존재 필수 확인.

## 이후 단계 (Lv 작성)
- `## 원본` 채운 뒤 Lv.1/Lv.4는 **동급 완성본을 템플릿으로**(예 2025_minso_2sun_10_01.md) [[dev-le-17895-toc-extract]] 형식:
  - Lv.1: `### 목차`(1./3칸-/6칸·) + 설문별 prose. Lv.4: 목차(복붙) + `### 설문 N — 주제 — [key]…[/key]` + `[con]결론` + 번호 + [case]/[fact]/[key]/[bridge]/[em1].
  - 한자 인명(甲乙丙丁) 유지(시각 과목), 판례번호 제거, 날짜 정규화(시효 필수분 유지), 조문 제N조 앞배치.
  - [em1] 두문자는 **원본에 실제 열거된 요건만**(가짜 두문자 금지). 매핑 없으면 [key].
- `_file_index.json` title: 설문별 쟁점 콤마 나열. points = 점수.
