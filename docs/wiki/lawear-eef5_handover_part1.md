## 6. 주요 의사결정

### D1. R-09 검증 방식 — 1차 QA → 2차 QA 다단 게이트

- **상황**: 1차 QA(부장판사+강사 Opus+ultrathink)가 사용자.md만으로 R-09 위반 11건 의심
- **선택지**:
  - (A) 1차 QA 신뢰하고 11건 모두 정정
  - (B) 2차 QA에서 강사 PDF 추가 비교
- **결정**: (B) — 1차 QA가 사용자.md만 봤다는 사실 자체가 한계. 강사 PDF가 진본
- **결과**: 70% 의견 철회. 풀이만 3건 위반 확정
- **교훈**: 부장판사+강사 QA도 "비교 대상이 사용자.md뿐"이면 오판 가능. 강사 PDF 비교가 필수 게이트

### D2. 추적성 메타 도입 (de044a7)

- **상황**: 라이브러리 검증 시 매번 사용자.md/PDF를 다시 grep해야 함
- **선택지**:
  - (A) 본문에 출처 inline
  - (B) 부록 별도 분리
  - (C) 본문은 간결, 부록만 절대경로 풀버전
- **결정**: (C) — 가독성과 검증 가능성 분리 (UT3 부록 A 도출)
- **결과**: 본문 1468/1362줄 + 부록 145/128줄 = 가독성 보존하면서 추적성 확보
- **교훈**: 단일 형식보다 용도별 분리가 더 효율적
