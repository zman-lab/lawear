## 두문자 입력 워크플로우

사용자가 김기찬 강사 PDF 박스 보고 정리:

```
좌표: {연도}/{순환}/{모고N}/{문N}/{섹션명}
두문자: A/B/C/...

예:
좌표: 2025/2순환/모고3/문2/진정성보장
두문자: 판/신/소/가/가/촉/수/동

좌표: 2025/2순환/모고3/문2/성질상불가
두문자: 보/상/표시/규약/소재불명
```

박스 = **1~N 글자 단어 단위 (가변)**. 사용자 인지 우선 적용.
