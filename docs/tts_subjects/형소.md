# 형소 (형사소송법) TTS 세부 규칙

> tts_rules.md 공통 규칙(R-01~R-24) + 이 파일의 세부 규칙을 함께 적용.

## Lv.1 포맷: C1~C5 구조

형소 답안은 아래 섹션으로 구분하여 TTS 텍스트를 작성한다.
문장이 길면 번호를 매겨 분리 (TTS 끊어 듣기 편하게).

```
C1-쟁점,
1. {쟁점 내용}

C2-{목차항목1},
1. {내용}
2. {내용}

C3-{목차항목2},
1. {내용}
2. {내용}

C4-결론,
1. {사안 포섭 내용}
2. {판례 근거 + 위법/적법 판단}

C5-보충,
1. {보충 설명}
2. {관련 판례}
3. {기타}
```

### C 번호 매핑
- C1 = 항상 쟁점 (원문 ① 문제제기에 해당)
- C2~C3 = 목차 항목 (개수는 답안에 따라 유동적, C2만 있을 수도 C4까지 있을 수도)
- C{마지막-1} = 결론 (사안 포섭 + 판례 근거 + 최종 판단)
- C{마지막} = 보충 (사실관계 단순화, 관련 판례 나열, 각주 등)

## 목차 추출 규칙

형소 답안은 두 유형이 있다:

### 유형A: 소제목이 있는 답안 (제3문, 제4문 등)
- 원문의 "1. 의의", "2. 특색", "(2) 참여권 여부" 등 소제목을 그대로 목차로 사용
- R-07 준수 (원문 그대로)

### 유형B: 소제목 없이 ①②③④⑤ 연속 논증 (제1문, 제2문 등)
- 원문 각 번호(①②③...)의 첫 문장에서 키워드/소제목을 추출하여 목차 구성
- 예: ② "제33조의 국선변호인 제도의 취지와 내용 :" → 목차: "국선변호인 제도의 취지와 내용"
- 예: ③ "피고인에게 유리한 양형요소를 주장할 필요성이 있는 경우," → 목차: "유리한 양형요소 주장 시 국선변호인 선정 필요성"
- 쟁점(①)과 결론(마지막 번호)은 목차에서 제외 (C1, C4로 별도 처리)

## 문제 스타일

- 구어체 ("~있음", "~됐다", "~받음", "~나왔음")
- 질문 끝: "적법한가?", "타당한가?", "인정할 수 있는가?"
- 쉼표로 사실관계 나열, 짧은 문장
- 날짜/판례번호 생략 (R-01, R-02)
- 숫자 한글화: 12회→십이회, 8회→팔회 등 (R-15, R-21)

## Lv.2 A/B/C/F

- A = 쟁점 (C1에서 축약)
- B = 결론 (위법/적법/부당 등 1줄)
- C-1, C-2... = 목차 항목과 1:1 매칭 (C2, C3의 축약)
- F = 포섭 (C4의 축약, 사안+판례+결론 통합)
- C5(보충)은 Lv.2에서 생략

## Lv.3 슈퍼심플

- A = 쟁점 (조문번호만, R-24 Lv3)
- B = 결론 (1~2단어)
- C-1, C-2... = 핵심 키워드만
- F = 포섭 1줄
- 문제/목차 없음

## 형소 답안 구조 참고 (#760)

형소 패턴: 쟁점→조문/제도→판례→사안포섭
- 결론 위치: 중간 (Ⅰ에서 선언)
- 판례: 별도 나열 또는 논증 안에 내장
- 조문: 맨 처음 또는 논증 안에 내장
- 사실관계 단순화: 별도 섹션
