# 채권자 대위 소송

## 당사자적격과 소송물
* 법소담 - 당사자적격 보필불 직권조사사항 - 개,자,시,결과(소송요건심리의 선순위)
* 소송물 - 대
* 계,승,국,사 / 지,패 / 패,총
* 피보전권리 부존재 판단시 당사자적격 흠으로 부적법 소각하 해야한다. 간과하고 본안 심리판단한것은 위법하다.

## 피보전채권의 존재 (계,승,국,사) - '형'이랑 '다툼'은 '무,제'
* 계승국사
* '형'이랑 '다툼'은 '무,제' -> 채무자가 채권자에 대해 갖는 항변권,형성권등과 같이 권리자에 의한 행사를 필요로 하는 사유를 들어 피보전권리를 다툴 수 없지만, 피보전권리의 발생원인이 된 법률행위가 무효 혹은 변제로 소멸등의 사실을 주장하여 피보전권리 인정 여부를 다투는것은 가능하다.
** 대위소송과 '계'약명의신탁 -> '형'이랑 '다툼'은 '무,제'
** 피보전권리 '승'소 후 대위 -> 승소판결로 피보전채권 존재는 입증된것과 같으므로, 제3채무자는 그 청구권의 존재를 다툴 수 없다.
** '국'토법 위반과 3자간 등기명의신탁 -> 피보전권리 취득이 강행법규 위반으로 무효인경우 제3채무자에 대한 관계에서는 피보전채권이 부존재함으로 봐야한다.
** 채무자가 '사'망 -> 채무자가 허무인 or 사망자라면 당사자적격이 없어 부적법하다.

## 보전의 필요성(지,패) - 보,수         (공분청)
* 채권자의 공동상속인의 '지'분초과 - 지분초과 부분은 '보'전의 필요성을 인정 할 '수' 없다
* 피보전권리관한 소송에서 '패'소확정 후 대위소송 - 기판력으로 인해 더이상 청구할수 없으므로, 청구권의 '보'전의 필요성을 인정 할 '수' 없다

## 채무자의 권리 불행사(패,총)
* 채무자 '패'소확정 후 대위권 행사 -> 당사자적격 없다.
* 비법인사단의 '총'유재산에 관한 소가 결의 흠결로 각하 후 대위행사 - 채무자 스스로 권리행사로 볼 수 없다

## 피대위권리 - 청,취,통,개,류x / 해,탈o (공분청)
* 대위불가능한 권리 - '청'약이나 승낙 / 후견인이 친족회 동의 없을때 '취'소권 / 채권양도'통'지 / '개'개의 소송행위 / 유'류'분반환청구권(권리행사의 확정적의사 있을때만 소송물인정)
* 대위 가능 - '해'제권 / 조합'탈'퇴권
* 공분청 - 금전채권 보전 위한 부동산의 '공유물분할청구권 행사'는 책임재산 보전과 직접 관련 없고, 채무자의 재산관리행위에 부당한 간섭이 되므로 보전의 필요성을 인정 할 수 없다.

# 채권자 취소 소송

## 소의 적법성과 본안 요건
1. 피,대,기 - 각 / 피,해(사),사 - 기
2. 피고적격 - 수,전o, 무x
3. 대상적격 - 무,수o, 수,전x
4. 기간준수: 성,적,판,명 - '안',1,행,5
'안'- '단순히 아,부'로는 안되고 '행,사'를 '알'아야!
