## 문제 1. 연대하여 — 연대채무 (2인 연대채무자)

### 조건
甲과 乙이 원고에게 10,000,000원의 연대채무를 부담.

### 청구취지 (cloze)

피고들은 [blank]연대하여[/blank] 원고에게 10,000,000원을 지급하라.

### 힌트 (5단계)

- **hint_1 (청구 유형)**: 금전지급 청구 — 수인의 연대채무자에게 함께 청구
- **hint_2 (청구취지 골격)**: 피고들은 ___ 원고에게 10,000,000원을 지급하라.
- **hint_2.5 (사례 키워드 매칭)**: 연대채무 = 연대하여
  ※ 혼동 포인트: 공동불법행위(공동하여)·분할채무(각)와 혼동 주의. 어음·수표(합동하여)와도 다름.
- **hint_3 (연결어 후보)**: 연대하여 / 공동하여 / 각
- **hint_4 (적용 룰)**: 주관적 병합 표 — 연대채무자, 주채무자와 연대보증인, 사용대차·임대차 공동차주, 일상가사 부부채무, 병존적 채무인수 = "연대하여"
- **hint_5 (key element 1개)**: 연결어 = "연대하여"

## 문제 7. 각 — 분할채무 (액수·기간·이율 상이)

### 조건
채무자 甲: 대여금 5,000,000원, 대여일 2019.6.19., 약정이자 연 12%
채무자 乙: 대여금 6,000,000원, 대여일 2019.11.28., 약정이자 연 15%

### 청구취지 (cloze)

원고에게 피고 甲은 5,000,000원 및 이에 대하여 2019.6.19.부터 다 갚는 날까지 연 12%의 비율로 계산한 돈을, 피고 乙은 6,000,000원 및 이에 대하여 2019.11.28.부터 다 갚는 날까지는 연 15%의 비율로 계산한 돈을 [blank]각[/blank] 지급하라.

### 힌트 (5단계)

- **hint_1 (청구 유형)**: 수인의 피고에게 별개의 청구 (액수·기간·이율 상이) — 분할채무
- **hint_2 (청구취지 골격)**: 원고에게 피고 甲은 ...을, 피고 乙은 ...을 ___ 지급하라.
- **hint_2.5 (사례 키워드 매칭)**: 분할채무 (액수·기간·이율 상이) = 각
  ※ 혼동 포인트: "연대하여"(연대보증)와 다름. 피고별로 액수·이율 다르면 분할채무 → 끝에 "각" (또는 항 분리).
- **hint_3 (연결어 후보)**: 연대하여 / 공동하여 / 각
- **hint_4 (적용 룰)**: 피고별로 청구가 분리된 분할채무 = 끝에 "각"
- **hint_5 (key element 1개)**: 연결어 = "각"

## 문제 10. 연대보증인과 연대하여 — 상속채무 + 연대보증 (idea3형)

### 조건
A의 대여금채무 70,000,000원, 피고 甲·乙의 연대보증, A 사망으로 배우자 丙이 30,000,000원, 자녀 丁이 20,000,000원 상속.

### 청구취지 (cloze)

원고에게, 피고 甲과 피고 乙은 연대하여 70,000,000원을, [blank]위 피고들과 연대하여[/blank] 위 돈 중 피고 丙은 30,000,000원을, 피고 丁은 20,000,000원을 각 지급하라.

### 힌트 (5단계)

- **hint_1 (청구 유형)**: 채무상속 응용형 — 연대보증 + 상속분할 혼합
- **hint_2 (청구취지 골격)**: 원고에게, 피고 甲과 피고 乙은 ___ 70,000,000원을, ___ 위 돈 중 피고 丙은 30,000,000원을, 피고 丁은 20,000,000원을 ___ 지급하라.
- **hint_2.5 (사례 키워드 매칭)**: 상속채무 + 연대보증인 중첩 = 위 피고들과 연대하여

## 문제 11. 연대보증인과 연대하여 — 일반보증 + 상속 응용

### 조건
A의 대여금채무 48,000,000원, 피고 甲·乙의 연대보증, A 사망으로 甲·丙·丁·戊가 각 24,000,000원, 16,000,000원, 4,000,000원, 4,000,000원씩 채무 상속 (甲은 연대보증인 겸 상속인).

### 청구취지 (cloze)

원고에게, 피고 甲과 피고 乙은 연대하여 48,000,000원을, [blank]위 피고들과 연대하여 위 돈 중[/blank] 피고 丙은 16,000,000원을, 피고 丁과 피고 戊는 각 4,000,000원을 각 지급하라.

### 힌트 (5단계)

- **hint_1 (청구 유형)**: 채무상속 응용형 — 연대보증 + 상속분할 (피고별 분담액 상이)
- **hint_2 (청구취지 골격)**: 원고에게, 피고 甲과 피고 乙은 ___ 48,000,000원을, ___ 피고 丙은 16,000,000원을, 피고 丁과 피고 戊는 ___ 4,000,000원을 ___ 지급하라.
- **hint_2.5 (사례 키워드 매칭)**: 상속채무 + 연대보증인 중첩 (응용·분담액 상이) = 위 피고들과 연대하여 위 돈 중
  ※ 혼동 포인트: 상속인 중 일부가 같은 금액 부담일 때만 그 부분에 "각" 추가. 단독 상속인은 "각" 없이 단순 분담액 표기.
- **hint_3 (연결어 후보)**: 연대하여 / 공동하여 / 각 / 연대보증인과 연대하여
- **hint_4 (적용 룰)**: 연대보증인끼리 = "연대하여", 상속인 중첩 = "위 피고들과 연대하여 위 돈 중", 상속인이 둘 다 같은 금액 부담 = "각", 청구 끝 = "각 지급하라"
- **hint_5 (key element 1개)**: 중첩 표현 = "위 피고들과 연대하여 위 돈 중"

## 문제 12. 연대보증인과 연대하여 — 단독 상속인 응용

### 조건
A의 대여금채무 50,000,000원, 피고 甲·乙의 연대보증. A 사망으로 배우자 丙이 50,000,000원 전액 상속.

### 청구취지 (cloze)

원고에게, 피고 甲과 피고 乙은 연대하여 50,000,000원을, [blank]위 피고들과 연대하여[/blank] 위 돈 중 피고 丙은 50,000,000원을 각 지급하라.

### 힌트 (5단계)

- **hint_1 (청구 유형)**: 채무상속 응용형 — 연대보증 + 단독 상속 (배우자가 전액 상속)
- **hint_2 (청구취지 골격)**: 원고에게, 피고 甲과 피고 乙은 ___ 50,000,000원을, ___ 위 돈 중 피고 丙은 50,000,000원을 ___ 지급하라.
- **hint_2.5 (사례 키워드 매칭)**: 단독 상속인 + 연대보증인 중첩 = 위 피고들과 연대하여
  ※ 혼동 포인트: 단독 상속이라도 연대보증인과 분할 청구되므로 청구 끝 "각" 유지. 청구 끝 "각" = "1인이라도 분할" 의미가 아니라 "연대보증채무·상속채무 두 줄기 분할"을 가리킴.
- **hint_3 (연결어 후보)**: 연대하여 / 공동하여 / 각 / 연대보증인과 연대하여
- **hint_4 (적용 룰)**: 연대보증인끼리 = "연대하여", 상속인이 연대보증인과 중첩 = "위 피고들과 연대하여", 청구 끝 = "각 지급하라" (상속인이 1인이지만 연대보증인과 분할되어 청구 끝은 "각" 유지)
- **hint_5 (key element 1개)**: 중첩 표현 = "위 피고들과 연대하여"
