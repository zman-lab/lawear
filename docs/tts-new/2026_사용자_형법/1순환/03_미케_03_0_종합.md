## Lv.1 빠른복습

### 문제

1순환 미케 제3회 종합: 정신차릴 정도로 때려라, 맥주담합 허위녹음, 프로포폴 취재, 부사장 이름 부름, 택시부회 폭행, 인감도장 날인, 모친 집 현금·등기필증, 누나 집 주민등록증의 결론은?

### 목차

1. 상해치사 교사·특수교사 / 2. 출판물명예훼손 간접정범 / 3. 프로포폴 종합 / 4. 모욕 / 5. 공동폭행·업무방해 / 6. 인감도장 사기 / 7. 현금·등기필증 / 8. 주민등록증 위조

### 답안

1. [bridge]문1[/bridge] 을은 위법한 명령 복종의무 없어 [red]살인죄[/red]. 갑은 "때려주라"=상해 교사, 사망 예견가능성 없어 상해교사 + 군대 지휘관계라 [red]특수교사(§34②)[/red].

2. [bridge]문2[/bridge] 乙 비방목적 없어 출판물명예훼손 불성립, 진실로 믿을 상당이유로 위법성조각 → [red]무죄[/red]. 甲은 목적 있는 우월적 지위라 [red]출판물명예훼손 간접정범[/red]+업무방해 상경.

3. [bridge]문3[/bridge] (1)폭처법위반·특수절도 성립가능, 변호인은 정당행위·불법영득의사 부정 주장. (2)명예훼손 위법성조각 가능. (다)법효과제한책임설로 방조범 긍정. (3)丙 공갈죄(직무의사 있으면 수뢰 상경).

4. [bridge]문4[/bridge] 15세 연장자 이름 부름은 무례하나 사회적 평가 저하 아님 → [red]모욕죄 불성립[/red].

5. [bridge]문5[/bridge] 甲乙 공동폭행([red]폭처법위반[/red])+택시업무 위력 방해([red]업무방해 공동정범[/red]), 폭행은 불가벌적 수반행위 아니라 [red]상상적 경합[/red].

6. [bridge]문6[/bridge] 인감도장 사용 후 즉시 반환은 불법영득의사 부정 → 절도 불성립. [red]사문서위조·동행사·사기[/red](사인부정사용 흡수).
