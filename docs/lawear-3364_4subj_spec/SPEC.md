## 9. [전과목 공통] 조문·규칙 마우스오버 → 원문 툴팁 + 법제처 데이터 수집
- **기능**: 모든 과목 답안의 `[case]` 조문/규칙 마커에 **마우스오버 → 해당 조문/규칙 원문을 툴팁**(§2 공통 컴포넌트)으로 표시. 인용 조문을 즉시 확인하며 학습.
- **전제 — 캐시에 원문 없음(확인됨)**: `web/src/data/lawArticles.json`(version 2026-03-22)은 article당 `title`(조문명)+`path`(장/절)만. **원문(body) 미보유 → 수집 필요.**
- **작업 (dev-team 데이터 파이프라인)**: 법제처 **국가법령정보 공동활용 API**로 캐시 내 전 법령(21개: 부등법/민법/형법/형사소송법/민사소송법/민사집행법/부동산등기규칙/상법/신탁법/공탁법/주택임대차보호법 등) **조문 원문 싹 수집 + 법령 개정분 업데이트**(title/구조 변경 재동기).
  - API: `www.law.go.kr/DRF/lawService.do?OC={키}&target=law&type=JSON`(법령 본문) — OC 키 무료 등록 필요. 법령명/MST/ID로 조회, 조·항·호 구조 파싱.
  - 저장: lawArticles.json article에 `content` 필드 추가 검토 — 단 **size 급증**(원문은 title의 수십 배) → 별도 원문 store(`lawArticlesText.json` 등) 분리 + (법명,조)키 매핑 권장. 항(項)/호(號) 단위 보존.
  - 툴팁 연결: `[case]` 마커 렌더 시 (법명,조[,항/호])→원문 lookup → data-comment(긴 원문은 lazy fetch/스크롤 박스). §2 `.inline-tooltip-portal`은 `max-width:360px`+`pre-wrap`이라 긴 원문은 스크롤 박스 변형 필요할 수 있음.
