1. 청구의 병합,
소비대차계약 기한 반환 청구와 지연손해금은 별개의 소송물로 객관적 병합에 해당한다.

### 사용자 작성본

- 번호 1~8

### 비교 분석
- **결론과 사안포섭 일부가 배치 불일치**: PDF 결론은 "해제되지 않았다"(매수인이 중도금 송금으로 이행착수 했으니 매도인의 해약금 해제 불가), 사용자 결론은 "적법하게 해제"

- **참고**: 단, 사용자가 번호 8에 "매수인이 이행기 전 착수 할 수 없는 특사에 해당하여, 매도인 의사에 반하여 일방적으로 이행 하더라도, 계약해제권 행사에 영향을 미칠 수 없다" — 이 문장이 실제로 사안 적용의 핵심. 결론 한 줄 요약이 PDF와 역방향일 수 있음은 사용자의 원본 이해 방식이 나머지 판례(제2판례 = 매도인이 해약금 해제 의사 후 매수인 중도금 송금도 제약) 쪽에 기울어진 결과로 보임.
  - 결국 원칙적으로 Lv.4의 **결론 문장 자체는 사용자 작성본 그대로 쓰지 말고 PDF 정답지 해시태그 기준으로 재검증** 필요. 가이드에 명시.
