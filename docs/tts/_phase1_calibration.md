## 가이드 수정 제안

### 수정안 1: V-01 번호 개수 규칙 강화 — "같은 쟁점 중복 설명 방지"

**배경**: Case 20에서 변환이 제135조 요건(대리행위/증명못할것/추인없을것/표현대리 안할것/행위능력자/선의무과실) 4개 요건을 번호 2에 추가했으나, 사용자는 증명책임만으로 번호 2개만 구성. Case 19(바로 앞)에서 이미 제135조 요건을 번호 6으로 자세히 다뤘기 때문에 Case 20에서는 **쟁점 불응하는 요건 설명을 생략**한 것.

**제안 추가 규칙 (V-01 보강)**:
```
V-01-a. 동일 조문·법리가 앞 Case에서 이미 다뤄진 경우:
- 같은 논점 나열을 반복하지 말 것
- 이어지는 Case에서는 해당 사안 고유 쟁점만 번호화
- 예: Case 19에서 제135조 요건 6개 완비 → Case 20에서는 증명책임만 초점
```

### 수정안 2: V-03 결론 형식 — "판례 이유를 결론으로 사용하는 복문 기준 명확화"

**배경**: Case 30에서 변환본은 "700만원/300만원 구상 가능"식 단순 결과형 결론. 사용자는 "부진정연대에서 면제는 상대적 효력에 불과하므로 ... 구상권 행사 할 수 있다"로 **판례 이유 자체를 결론으로** 복문 구성. 현재 가이드 V-03은 "Case 27, 30은 복문"만 명시.

**제안 추가 규칙 (V-03 보강)**:
```
V-03-a. 복문 결론 적용 기준:
- 쟁점이 복수이거나, 판례 이유 자체가 설문 답이 되는 경우 → 복문
- 결론 = 판례 이유 핵심 (예: "~이므로, ~할 수 있다" 식)
- 주문형 결론(700만원/300만원 등)은 **사용자 작성본에 없음** — 법리 판단만 제시
- 주문이 서로 다른 2개 피고를 향할 때(Case 30)도 "부진정연대에서 면제는 상대적 효력..."식으로 법리화
```

### 수정안 3: P-07 금액 처리 — "사안 주문의 구체 금액 제거" 명시 강화

**배경**: 현재 가이드 P-07: "금액이 쟁점이면 유지, 단순 사실관계면 제거. 일반화 가능한 숫자는 제거"는 정답. 그러나 Case 30 변환에서 "700만원/300만원"을 결론에 포함한 실수 발생 → 사용자 작성본 30개 전체에서 주문 금액은 **한 번도** 결론에 등장하지 않음.

**제안 추가 규칙 (P-07 보강)**:
```
P-07-a. 주문 금액 처리 절대 규칙:
- PDF 해시태그에 포함된 구체 금액(예: "700만 원", "300만 원")도 Lv.4 결론에서 **제거**
- 결론은 "~구상권 행사 가능하다"처럼 정성적 표현으로 고정
- 단 법정이율(연 5푼 / 연 5%)은 쟁점 금리이므로 유지 가능
```

### 수정안 4: P-01 결론 종결 형식 — "쉼표(,) 사용 빈도"

**배경**: 현재 가이드 P-01: "Case 22, 23, 24, 27, 28, 29, 30은 쉼표"로 명시. 실제 관찰: Case 18, 19, 20, 21, 22, 25, 27, 28, 29, 30이 쉼표 종결. 마침표 빈도 더 적음.

**제안 보강**:
```
P-01-a. 결론 쉼표 종결 디폴트:
- Lv.4 결론은 쉼표(,) 종결을 디폴트로 간주
- 마침표(.) 종결은 결론이 단문 단일쟁점인 경우만 (Case 1, 4, 5, 10 등)
- 복문 결론은 반드시 쉼표 종결
```
