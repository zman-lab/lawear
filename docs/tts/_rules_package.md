## 추가 규칙 R-01 ~ R-26

### R-01. 판례번호 완전 제거 (변환 X)
"(대판 2018.7.19. 2018다22008)" → 삭제

### R-02. 날짜 → 상대적 시간 표현
빈번한 날짜는 상대적 표현. 단 시효 계산 필수 날짜는 유지.

### R-03. 괄호(A(B)) → "A 혹은 B"
TTS가 괄호 못 읽음. "행위시법주의(소급효금지의 원칙)" → "행위시법주의 혹은 소급효금지의 원칙"

### R-04. 호흡 조절 쉼표 삽입
긴 문장은 쉼표로 끊어 읽기 유도. 단 과다 X.

### R-05. 콜론(:) → 쉼표(,)
"결론: 타당하지 않다" → "결론, 타당하지 않다"

### R-06. 문제 후 목차 먼저 → 답안 (Lv.1/2 한정)
Lv.4는 문제/목차 모두 제거이므로 N/A

### R-07. 목차는 원문 그대로 (Lv.1/2 한정)
Lv.4는 N/A

### R-08. 특수기호 제거
대상: `[]` `—` `:` `()` `/`

### R-09. AI 자의적 해석 금지 — 최상위 ⭐
- AI가 법률 지식으로 보충/해석/변경 X
- PDF에 있는 정보만 사용
- 의심스러우면 원본 표현 유지
- **다른 모든 룰과 충돌 시 R-09 우선**

### R-10. diff 필수 제공
원본 vs 변환 비교 항상 포함

### R-11. 듣는 사람 입장 QA 필수
- 구분되는가, 길이 OK, 날짜/인명 혼동 X, 법률 용어 정확

### R-12. 문제 부분 간결화
쉼표 최소화, 중복/수식어 제거. R-09 균형.

### R-13. 목차 상투적 항목 제거
"결론", "이유" 단독 항목 제거. "결론의 당부"는 유지.

### R-14. 제+숫자 한글화
제1심→제일심, 제3자→제삼자. 단 제44조/제216조 (조문번호)는 그대로.

### R-15. 숫자 한글화 + 불필요 수식어 생략
"현금 1000만원을 직접 건네며" → "천만원을 빌려주며"

### R-16. 조문 인용 시 제목 + 앞배치
"제397조" → "제397조 금전채무불이행에 대한 특칙에 의해..."

### R-17. 문맥 유추 정보 생략

### R-18. diff 누락 시 작업 미완료

### R-19. 조문 번호 아라비아 그대로

### R-20. 목록 번호 숫자
"첫째 둘째" X → "1. 2. 3." O

### R-21. 숫자 한글화 세부
- 금액: 한글화 O (1000만원→천만원)

## Lv.1 ~ Lv.4 정의

### Lv.1 빠른복습 (~3분)
- 문제: 간결화 (R-12)
- 목차: 원문 기반, R-13 적용
- 답안: 원문 클린 (교수메모 삭제, 학설대립 유지)

### Lv.2 핵심요약 (~1분30초)
- 문제: Lv.1과 동일
- 목차: Lv.1과 동일
- 답안: A/B/C/F 유연 구조
  - A. 쟁점 1줄
  - B. 결론 1~2줄
  - C. 이유 자유 구조 (목차 = C 소제목, 조문/판례 내장)
  - F. 포섭 핵심만

### Lv.3 슈퍼심플 (~30초)
- 문제: 없음
- 목차: 없음
- 답안: A/B/C/F 축약 문장 (키워드만 X, 짧은 문장)

### Lv.4 암기노트 (~1분, 사용자 스타일)
- 문제: 없음
- 목차: 없음
- 답안: 결론 한 줄 + 번호 매김 명제
  - 정답지(Case 1~30 민법) 직접 참조 학습
  - 가이드 `docs/tts/_lv4_user_style_guide.md` 우선

## 변환 서브에이전트 작업 순서

1. 자기가 담당할 PDF 텍스트 추출:
   `pdftotext -layout {PDF경로} - 2>/dev/null`
2. Case 단위 분리 (`^Case N` 패턴)
3. 각 Case에 대해:
   a. 원본 텍스트 정제 (기본 전처리 10개)
   b. Lv.1 변환 (문제 간결화, 목차 정리, 답안 클린)
   c. Lv.2 변환 (A/B/C/F 구조)
   d. Lv.3 변환 (A/B/C/F 축약)
   e. Lv.4 변환:
      - 가이드 `docs/tts/_lv4_user_style_guide.md` Read
      - **자기 PDF가 미케_01/02/03 (예비_민법)이고 Case 1~30 범위면**:
        - 사용자 작성본 `/Users/nhn/Documents/암기노트/민법/26_민법_미케.txt` Read
        - 해당 Case 부분 발췌 후 1:1 비교 학습
        - 사용자 패턴 그대로 재현
      - 그 외: 가이드만으로 변환
   f. diff 생성 (원본 vs 각 Lv)
   g. 체크리스트 10개 + R 적용표
   h. 파일 저장: `docs/tts/{과목}_{단계}/{Case_id}.md`

4. 진행률 보고 (메인 회수용 — 아래 형식)
